# Assistive Communication System for Disabled People

An intelligent web-based assistive communication platform designed to support blind, deaf, and speech-impaired individuals through emergency assistance, real-time communication, and accessibility-focused features.

---

## 📌 Project Overview

The Assistive Communication System helps differently-abled users communicate easily and request emergency assistance instantly. The platform provides separate dashboards for users and administrators with real-time monitoring and emergency alert handling.

---

## 🚀 Features

### 👤 User Module
- User Registration & Login
- Role-Based Access
- Disability Selection (Blind, Deaf, Speech-Impaired)
- Emergency Help Requests
- Quick Emergency Actions:
  - 💧 Need Water
  - 🍽 Need Food
  - 💊 Need Medicine
  - 📞 Call Help
- Real-Time Private Chat
- Speech Assistance Button
- Emergency SOS Button

### 🛠 Admin Module
- Admin Dashboard
- View All Registered Users
- Monitor Emergency Alerts
- Resolve Emergency Requests
- Alert Status Tracking
- Emergency Analytics
